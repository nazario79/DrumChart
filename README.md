# DrumChart

Chart da palco per batteristi, da leggere sul tablet durante i live.

- **Brani**: titolo, artista, BPM, attacco, struttura a blocchi (Intro, Strofa, Rit, Special, Stop…) con battute, ripetizioni e appunti.
- **Scalette**: per ogni brano scegli **Singolo** o **Medley**. Il medley aggancia il brano successivo con un **raccordo**: cambio di BPM (▲ accelera / ▼ rallenta), conteggi prima dell'entrata e una nota.
- **Modalità live**: schermo sempre acceso, barre nascoste, un brano per pagina, swipe o pedale Bluetooth (Pagina giù/su, frecce, spazio, invio) per cambiare brano, A−/A+ per la dimensione del testo.
- **Backup**: menu ⋮ → Esporta/Importa. Il selettore di Android permette di salvare e aprire il file direttamente da Google Drive. All'importazione scegli *Unisci* o *Sostituisci*.

## Installazione

Ogni push su `main` compila l'APK con GitHub Actions: lo trovi in **Releases** (`DrumChart-N.apk`).
